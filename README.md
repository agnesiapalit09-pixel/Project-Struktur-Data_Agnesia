# Project-Struktur-Data_Agnesia
Project Layanan Pengantaran Makanan/Barang

A. Deskripsi
    Proyek ini merupakan program untuk mengelola pesanan, antrean, dan laporan pesanan.
    
B. Struktur 
    Folder backend = Menyimpan logika program dan pengolahan pesanan.
    Folder frontend = Menyimpan bagian UI bagi pengguna.
    Folder database = Menyimpan data yang digunakan untuk penyimpanan data.
    app.py 

C. Cara Menjalankan
    Download setiap file lalu jalankan dari file ui.py

D. Fitur
    1. M1 = Data Pesanan, Array vs Linked List
    2. M2 = Stack & Queue
    3. M3 = Sort & Search
